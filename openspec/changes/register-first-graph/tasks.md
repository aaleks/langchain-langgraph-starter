# Sequence

- **Order:** the dependencies and the `fake_llm` fixture first -- nothing else
  can be written without them. Then ASSISTANT-TOOL-LOOP, which creates the
  factory; ASSISTANT-MODEL-CALL-BUDGET bounds the loop the factory compiles;
  ASSISTANT-REGISTERED wires the factory to the registry and `langgraph.json`
  last, the ladder's build order (state, node, transition, fake-model run, then
  registration).
- **Wiring point:** `src/starter/infrastructure/agents/registry.py`'s
  `assistant`, named by `langgraph.json` -- what the local server loads.
- **Story test:** `tests/acceptance/agents/test_registered_assistant.py::TestAssistantIsRegistered`
  -- ASSISTANT-REGISTERED's proof, red until the registry and `langgraph.json`
  exist.
