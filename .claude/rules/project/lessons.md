# This project's own lessons

The rules under `.claude/rules/sdd/` and the stack packs state invariants that
hold for any project using the method. This file is for **yours**: the traps,
the surprises and the decisions that only make sense here.

It is the declared fallback of `/learn`, not its default. A lesson goes here
only when it could not become a requirement, a check, a guard or a fixture --
and the entry says why. Write the reason, not just the rule: "a local model
does not make the web local" is worth keeping; "check the API key" is not.

Empty is the honest state of this file on day one.
